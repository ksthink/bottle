# 소리 파일

이 폴더에 아래 이름으로 mp3를 넣으면 게임이 자동으로 씁니다. `npm run dev`와 `npm run build`가 시작할 때 이 폴더의 파일 목록을 `manifest.json`으로 적고, 게임은 목록에 있는 파일만 받아 옵니다.
파일이 없으면 환경음은 브라우저에서 합성한 소리로 대신하고, 효과음은 나지 않습니다.

| 파일 | 내용 | 비고 |
|------|------|------|
| waves.mp3 | 파도 | 반복 재생, 가까운 해안에서 들림 |
| wind.mp3 | 바람 | 반복 재생, 바람 세기에 따라 |
| rain.mp3 | 비 | 반복 재생, 빗줄기에 따라 |
| fire.mp3 | 모닥불 | 반복 재생, 불 자리에서 |
| gulls.mp3 | 갈매기 | 낮에 이따금 |
| step_sand_1~4.mp3 | 마른 모래 발소리 | 테이크 여러 개를 섞어 씀 |
| step_wet_1~4.mp3 | 젖은 모래 발소리 | |
| step_grass_1~4.mp3 | 풀밭 발소리 | |
| step_water_1~4.mp3 | 얕은 물 첨벙 | |
| log_1~4.mp3 | 장작 넣기 | |
| thunder_1~4.mp3 | 천둥 | 번개 뒤 조금 늦게 |

테이크는 1~4개 중 몇 개든 됩니다(`_1` 없이 `log.mp3`처럼 넣어도 됨).

`public/sounds/fetch.txt`에 `파일이름 주소`를 한 줄씩 적어 올리면 GitHub Actions가 내려받아 이 폴더에 커밋합니다.
