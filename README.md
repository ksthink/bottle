# 유리병 편지 섬

혼자 사는 작은 섬에 유리병 편지가 밀려옵니다. 읽고, 쓰고, 바다에 던지면 이름 모를 누군가에게 닿습니다. 답장도, 읽음 표시도 없습니다.

- `index.html` — 3D 시제품 (three.js r128, 단일 파일, 빌드 없음)
- `PLAN.md` — 서비스 계획서 (규칙, 세계관, Vercel + Supabase 설계, 개발 단계)

## 로컬 실행

```sh
npx serve .
```
